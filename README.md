# LLM API Practice

This is a practice project I made while learning Generative AI and working with different APIs.

In this project, I explored text generation, query answering, email summarization, and image generation.

## Technologies Used

- Python
- OpenAI API
- Groq API
- Hugging Face
- Streamlit

## What I Implemented

### Text Generation
Used OpenAI and Groq APIs to generate responses for user queries.

### Query Answering
Used LLM APIs to ask questions and get answers.

### Email Summarization
Implemented email summarization using an LLM to get the main information from an email.

### Image Generation
Used Hugging Face Inference API to generate images from text prompts.

For image generation, I used:

- Provider: `fal-ai`
- Model: `black-forest-labs/FLUX.1-schnell`
